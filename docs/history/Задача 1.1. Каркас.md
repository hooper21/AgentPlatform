ЧАСТЬ 1. СТРУКТУРА SOLUTION (.NET 10)

Создай solution со следующими проектами (clean architecture, слой = проект):
- AgentPlatform.Core          — контракты, DTO, enums, StateContract; НЕ зависит ни от чего
- AgentPlatform.Gateway       — ASP.NET Core (minimal APIs)
- AgentPlatform.Runtime       — Microsoft.Agents.AI.Workflows (заглушка реализации)
- AgentPlatform.LlmGateway    — обёртка IChatClient (Microsoft.Extensions.AI)
- AgentPlatform.ConnectorHost — ModelContextProtocol SDK 2.x (заглушки коннекторов)
- AgentPlatform.Knowledge     — инжест/поиск (заглушки)
- AgentPlatform.TenantApp     — ASP.NET Core API (SPA добавим позже)
- AgentPlatform.Controller    — внутренний API платформы
- AgentPlatform.Scheduler     — консольный сервис-планировщик
- AgentPlatform.Tests         — xUnit

Зависимости: все сервисные проекты ссылаются на Core; тесты — на все.
Заглушки сервисов собираются и стартуют, реальная логика — в следующих задачах.
Правило: не добавляй библиотеки сверх указанных в этой задаче (EF Core
Npgsql, Microsoft.Agents.AI, Microsoft.Extensions.AI, ModelContextProtocol,
Redis.StackExchange, xUnit).

ЧАСТЬ 2. МОДЕЛЬ ДАННЫХ (PostgreSQL, EF Core, полный DDL ниже)

Требования к реализации:
- EF Core 10 + Npgsql, миграции через dotnet ef database update.
- Все таблицы с tenant_id имеют B-tree индекс (tenant_id, ...) — первый
  столбец составных индексов.
- jsonb-поля — без строгих CHECK-схем в v1 (схемы валидируются кодом),
  кроме approval.gate_payload и agents.rules — там REQUIRED-валидация кодом.
- Идентификаторы: Guid (uuid v4), генерация на стороне приложения.
- Метки времени: timestamptz (UTC). created_at / updated_at — на всех таблицах,
  EF interceptors, не триггеры.
- Никаких каскадных удалений по умолчанию: FK — ON DELETE RESTRICT,
  кроме явно помеченных ON DELETE CASCADE (сообщения и чекпоинты сессии).

-- ===== Справочники платформы =====

CREATE TABLE tenants (
    id              uuid PRIMARY KEY,
    name            varchar(200) NOT NULL,
    plan            varchar(50)  NOT NULL DEFAULT 'pilot',      -- pilot | basic | unlimited
    llm_config      jsonb        NOT NULL,                      -- {mode: "platform"|"own", endpoint?, api_key_ref?, model}
    status          varchar(20)  NOT NULL DEFAULT 'active',     -- active | blocked
    created_at      timestamptz  NOT NULL DEFAULT now(),
    updated_at      timestamptz  NOT NULL DEFAULT now()
);

CREATE TABLE users (
    id              uuid PRIMARY KEY,
    tenant_id       uuid NOT NULL REFERENCES tenants(id),
    email           varchar(320) NOT NULL,
    password_hash   varchar(500) NOT NULL,
    role            varchar(20)  NOT NULL,                      -- admin | operator | viewer
    auth_meta       jsonb        NOT NULL DEFAULT '{}',
    created_at      timestamptz  NOT NULL DEFAULT now(),
    updated_at      timestamptz  NOT NULL DEFAULT now(),
    UNIQUE (tenant_id, email)                                   -- email уникален ВНУТРИ тенанта
);
CREATE INDEX ix_users_tenant ON users (tenant_id);

CREATE TABLE connector_registry (                                -- каталог коннекторов (платформенный)
    id              uuid PRIMARY KEY,
    name            varchar(100) NOT NULL,
    version         varchar(20)  NOT NULL,
    manifest        jsonb        NOT NULL,                      -- ConnectorManifest + JSON Schema
    manifest_hash   varchar(64)  NOT NULL,                      -- sha256 для верификации
    publisher       varchar(100) NOT NULL,
    status          varchar(20)  NOT NULL DEFAULT 'published',  -- draft | published | deprecated
    created_at      timestamptz  NOT NULL DEFAULT now(),
    updated_at      timestamptz  NOT NULL DEFAULT now(),
    UNIQUE (name, version)
);

-- ===== Установки коннекторов и тул-политики =====

CREATE TABLE connector_installations (
    id              uuid PRIMARY KEY,
    tenant_id       uuid NOT NULL REFERENCES tenants(id),
    registry_id     uuid NOT NULL REFERENCES connector_registry(id),
    credentials_ref varchar(200) NOT NULL,                      -- ССЫЛКА на секрет в Secret Service, НЕ сам секрет
    auth_type       varchar(30)  NOT NULL,                      -- apiKey | longLivedToken | oauth2 | external_mcp
    external_url    varchar(500) NULL,                          -- для сторонних MCP-серверов (PF16)
    status          varchar(20)  NOT NULL DEFAULT 'active',     -- active | error | disabled
    last_health_check timestamptz NULL,
    health_meta     jsonb       NOT NULL DEFAULT '{}',         -- счётчики ошибок, 429, последняя ошибка
    created_at      timestamptz NOT NULL DEFAULT now(),
    updated_at      timestamptz NOT NULL DEFAULT now()
);
CREATE INDEX ix_ci_tenant ON connector_installations (tenant_id);

CREATE TABLE tool_settings (
    id                  uuid PRIMARY KEY,
    installation_id     uuid NOT NULL REFERENCES connector_installations(id) ON DELETE CASCADE,
    tool_name           varchar(200) NOT NULL,
    enabled             boolean      NOT NULL DEFAULT true,
    policy              varchar(20)  NOT NULL,                  -- read | write | destructive (из манифеста; понижение допустимо, повышение — нет)
    policy_source       varchar(20)  NOT NULL,                  -- manifest | tenant_override
    description_override text       NULL,
    gate_settings       jsonb        NOT NULL DEFAULT '{}',     -- {mode: "always"|"conditional"|"never", predicate?...}
    created_at          timestamptz  NOT NULL DEFAULT now(),
    updated_at          timestamptz  NOT NULL DEFAULT now(),
    UNIQUE (installation_id, tool_name)
);
CREATE INDEX ix_ts_tenant ON tool_settings (installation_id);

-- ===== Агенты и версии =====

CREATE TABLE agents (
    id              uuid PRIMARY KEY,
    tenant_id       uuid NOT NULL REFERENCES tenants(id),
    name            varchar(200) NOT NULL,
    current_version integer      NOT NULL DEFAULT 1,
    created_at      timestamptz  NOT NULL DEFAULT now(),
    updated_at      timestamptz  NOT NULL DEFAULT now(),
    UNIQUE (tenant_id, name)
);

CREATE TABLE agent_versions (                                    -- PF2: неизменяемые версии, откат = переключение указателя
    id                  uuid PRIMARY KEY,
    agent_id            uuid NOT NULL REFERENCES agents(id),
    version             integer NOT NULL,
    status              varchar(20) NOT NULL,                   -- draft | proposed | published | archived
    system_prompt       text    NOT NULL,
    model_ref           jsonb   NOT NULL,                       -- {endpoint?, model, routing: simple|complex}
    enabled_tools       jsonb   NOT NULL,                       -- [{installation_id, tool_name, policy}]
    rules               jsonb   NOT NULL DEFAULT '{}',          -- правила квалификации, ограничения
    escalation_rules    jsonb   NOT NULL DEFAULT '{}',          -- триггеры: sentiment, failed_turns, ...
    limits              jsonb   NOT NULL DEFAULT '{}',          -- max_turns, max_tool_calls, max_tokens
    proposed_by_ops     boolean NOT NULL DEFAULT false,         -- черновик от агента качества (platform-ops)
    created_by          uuid    NULL REFERENCES users(id),      -- null = создано системой/Scheduler
    created_at          timestamptz NOT NULL DEFAULT now(),
    UNIQUE (agent_id, version)
);
CREATE INDEX ix_av_agent ON agent_versions (agent_id, version);

-- ===== Каналы и знания =====

CREATE TABLE channels (
    id              uuid PRIMARY KEY,
    tenant_id       uuid NOT NULL REFERENCES tenants(id),
    type            varchar(30) NOT NULL,                       -- widget | telegram | (плагины)
    config          jsonb       NOT NULL,                       -- брендирование, секрет JWT виджета — по ссылке
    widget_secret_ref varchar(200) NULL,                        -- ссылка на секрет подписи JWT (для widget)
    status          varchar(20) NOT NULL DEFAULT 'active',
    created_at      timestamptz NOT NULL DEFAULT now(),
    updated_at      timestamptz NOT NULL DEFAULT now()
);
CREATE INDEX ix_ch_tenant ON channels (tenant_id);

CREATE TABLE knowledge_sources (
    id              uuid PRIMARY KEY,
    tenant_id       uuid NOT NULL REFERENCES tenants(id),
    type            varchar(30) NOT NULL,                       -- document | site | faq
    ref             varchar(500) NOT NULL,                      -- путь к файлу / URL / —
    title           varchar(300) NOT NULL,
    chunk_count     integer     NOT NULL DEFAULT 0,
    index_status    varchar(20) NOT NULL DEFAULT 'pending',     -- pending | indexing | ready | error
    index_meta      jsonb       NOT NULL DEFAULT '{}',          -- ошибки инжеста, время последнего прогона
    created_at      timestamptz NOT NULL DEFAULT now(),
    updated_at      timestamptz NOT NULL DEFAULT now()
);
CREATE INDEX ix_ks_tenant ON knowledge_sources (tenant_id);

CREATE TABLE knowledge_chunks (                                  -- pgvector, для задачи 2.3 — сразу заложить
    id              bigserial PRIMARY KEY,
    tenant_id       uuid NOT NULL REFERENCES tenants(id),
    source_id       uuid NOT NULL REFERENCES knowledge_sources(id) ON DELETE CASCADE,
    content         text    NOT NULL,
    metadata        jsonb   NOT NULL DEFAULT '{}',              -- заголовки, позиция, страница
    embedding       vector(1024),                               -- размерность из модели-эмбеддера, уточняется при установке
    created_at      timestamptz NOT NULL DEFAULT now()

CREATE INDEX ix_kc_tenant_source ON knowledge_chunks (tenant_id, source_id);
CREATE INDEX ix_kc_embedding ON knowledge_chunks USING ivfflat (embedding vector_cosine_ops) WITH (lists = 100);

-- ===== Сессии и диалоги =====

CREATE TABLE sessions (
    id              uuid PRIMARY KEY,
    tenant_id       uuid NOT NULL REFERENCES tenants(id),
    agent_id        uuid NOT NULL REFERENCES agents(id),
    agent_version   integer NOT NULL,                           -- version pinning: версия, на которой началась сессия
    channel_id      uuid NOT NULL REFERENCES channels(id),
    user_ref        varchar(200) NOT NULL,                      -- идентификатор визитера канала
    status          varchar(20) NOT NULL DEFAULT 'active',      -- active | awaiting_gate | escalated | operator | closed | degraded
    meta            jsonb       NOT NULL DEFAULT '{}',          -- счётчики ходов, флаги эскалации, debounce
    started_at      timestamptz NOT NULL DEFAULT now(),
    last_activity_at timestamptz NOT NULL DEFAULT now(),
    closed_at       timestamptz NULL
);
CREATE INDEX ix_se_tenant_status ON sessions (tenant_id, status);
CREATE INDEX ix_se_user ON sessions (tenant_id, user_ref);

CREATE TABLE messages (
    id              bigserial PRIMARY KEY,
    session_id      uuid NOT NULL REFERENCES sessions(id) ON DELETE CASCADE,
    tenant_id       uuid NOT NULL REFERENCES tenants(id),       -- денормализация для tenant-фильтров
    role            varchar(20) NOT NULL,                       -- user | assistant | tool | operator | system
    content         text    NOT NULL,
    tool_calls      jsonb   NULL,                               -- [{name, args_masked, result_ref, latency_ms}]
    ts              timestamptz NOT NULL DEFAULT now()
);
CREATE INDEX ix_me_session ON messages (session_id, ts);

CREATE TABLE checkpoints (                                       -- нейтральный JSON-контракт, НЕ формат рантайма
    id              bigserial PRIMARY KEY,
    session_id      uuid NOT NULL REFERENCES sessions(id) ON DELETE CASCADE,
    tenant_id       uuid NOT NULL REFERENCES tenants(id),
    superstep       integer NOT NULL,
    state           jsonb   NOT NULL,                           -- {messages, pending_gate, counters, version}
    graph_signature_hash varchar(64) NOT NULL,                  -- хеш топологии графа для валидации resume
    created_at      timestamptz NOT NULL DEFAULT now(),
    UNIQUE (session_id, superstep)
);
CREATE INDEX ix_cp_session ON checkpoints (session_id, superstep DESC);

-- ===== Гейты и аудит =====

CREATE TABLE approvals (                                         -- HITL-журнал
    id              uuid PRIMARY KEY,
    session_id      uuid NOT NULL REFERENCES sessions(id),
    tenant_id       uuid NOT NULL REFERENCES tenants(id),
    checkpoint_id   bigserial REFERENCES checkpoints(id),       -- из какого чекпоинта возобновлять
    gate_payload    jsonb   NOT NULL,                           -- {tool, args_masked, human_description, undo_hint}
    status          varchar(20) NOT NULL DEFAULT 'pending',     -- pending | approved | rejected | expired | superseded
    requested_at    timestamptz NOT NULL DEFAULT now(),
    expires_at      timestamptz NULL,                           -- таймаут тенанта (дефолт 24 ч)
    decided_by      uuid NULL REFERENCES users(id),             -- null, если решил пользователь канала
    decided_by_kind varchar(20) NULL,                           -- operator | user | system
    decision        varchar(20) NULL,
    decided_at      timestamptz NULL
);
CREATE INDEX ix_ap_pending ON approvals (tenant_id, status) WHERE status = 'pending';

CREATE TABLE tool_audit (                                        -- append-only, UPDATE/DELETE запрещены кодом
    id              bigserial PRIMARY KEY,
    tenant_id       uuid NOT NULL REFERENCES tenants(id),
    session_id      uuid NOT NULL REFERENCES sessions(id),
    tool_name       varchar(200) NOT NULL,
    installation_id uuid NOT NULL REFERENCES connector_installations(id),
    args_masked     jsonb   NOT NULL,
    outcome         varchar(20) NOT NULL,                       -- ok | error | denied | degraded | gate_required
    result_ref      varchar(500) NULL,                          -- ссылка на хранилище полного результата
    latency_ms      integer NULL,
    trace_id        varchar(64) NOT NULL,                       -- OTel trace correlation
    ts              timestamptz NOT NULL DEFAULT now()
);
CREATE INDEX ix_ta_tenant_ts ON tool_audit (tenant_id, ts DESC);
CREATE INDEX ix_ta_tool ON tool_audit (tenant_id, tool_name, ts DESC);

-- ===== Учёт, планирование, шаблоны =====

CREATE TABLE usage (

CREATE INDEX ix_sr_enabled ON scheduled_runs (enabled);

### Как запустить
```powershell
cd d:\DEV\AI\AgentPlatform\src
Copy-Item .env.example .env      # задать POSTGRES_PASSWORD и AGENTPLATFORM_SEED_ADMIN_PASSWORD
docker compose up --build        # postgres+pgvector, redis, one-shot migrate, 6 сервисов
```

### Как проверить миграции и seed
```powershell
$env:ConnectionStrings__Postgres = "Host=localhost;Port=5432;Database=agentplatform;Username=agentplatform;Password=<pw>"
dotnet ef database update --project AgentPlatform.Infrastructure      # накат на пустую БД
dotnet ef migrations script --project AgentPlatform.Infrastructure    # проверка без БД (выполнено)

$env:AGENTPLATFORM_SEED_ADMIN_PASSWORD = "<pw admin>"
dotnet run --project AgentPlatform.TenantApp -- --migrate --seed
curl http://localhost:8081/api/v1/internal/tenants
curl http://localhost:8081/api/v1/internal/tenants/<tenantId>/users
```
В compose это делает сервис `migrate` (tenant-app стартует через `service_completed_successfully`).

### Решения сверх задания (кратко, полностью — в README §8)
1. Добавлен проект **`AgentPlatform.Infrastructure`** — в списке задания слоя персистентности не было, а DbContext нужен TenantApp/Controller/Knowledge/Scheduler; правило «Core без EF» сохранено.
2. `bigint GENERATED BY DEFAULT AS IDENTITY` вместо `bigserial`; `approvals.checkpoint_id` → `bigint NULL` (в DDL `bigserial` на nullable FK дал бы мусорные значения).
3. pgvector (extension, `vector(1024)`, ivfflat) — сырым SQL в миграции: пакет `Pgvector` не в разрешённом списке.
4. Дублирующие индексы (`ix_av_agent`, `ix_cp_session` рядом с UNIQUE по тем же столбцам) объединены в один уникальный.
5. Добавлены tenant-first индексы, которых нет в DDL: `messages(tenant_id, ts)`, `checkpoints(tenant_id, session_id)`, `scheduled_runs(tenant_id, enabled)`.
6. jsonb в EF — `string` + `HasColumnType("jsonb")`, типизированные контракты и валидаторы в Core; snake_case-имена столбцов — собственной конвенцией (без `EFCore.NamingConventions`).
7. Пароли — PBKDF2-SHA256 (210k) вместо ASP.NET Identity/BCrypt; tenant-контекст — заглушка по `X-Tenant-Id` (TODO JWT); тесты данных на EF InMemory; один Dockerfile на все сервисы.
