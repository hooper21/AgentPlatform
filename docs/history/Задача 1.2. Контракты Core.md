## Решения сверх задания
1. `PauseAsync`/`ResumeAsync` возвращают `Task` (как в задании), а не `Task<RunResult>`: результат шага
   и `pending_gate` остаются зоной `RunAsync`/`GateExecutor`, чтобы не расширять контракт.
2. `GateRequirement` — вид (enum) + фабрики вместо иерархии записей: значение сериализуемо, набор видов закрыт,
   `Conditional` без предиката невозможен.
3. `external_mcp` сохранён в `ConnectorAuthType`: платформенные MCP-серверы (EchoTools, platform-ops) не требуют
   секрета тенанта; значения задания (`apiKey`, `longLivedToken`, `oauth2`) — основные.
4. JSON-представление манифеста — snake_case: манифест лежит в `connector_registry.manifest` jsonb, где
   действует конвенция ключей DDL (`gate_payload`, `rules`). Это же зафиксировано в JSON Schema.
5. `limits` в манифесте обязательны: платформа обязуется соблюдать лимиты, поэтому «не задекларировано» — ошибка установки.
6. `ChannelType` — строка, а не enum: новый канал должен быть плагином, а не правкой Core.
7. Валидатор манифеста не подключён к `AgentPlatformDbContext.SaveChanges`: install-flow коннекторов —
   задача 2.2; сейчас вызов выполняется при старте Connector Host и доступен каталогу/Controller как код-контракт.
8. Строгий разбор состояния (неизвестные ключи → ошибка) выбран как гарантия требования
   «рантайм-специфичные структуры через контракт не проходят»; расширение полей — только смена версии контракта.
