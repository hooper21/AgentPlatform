на Microsoft.Agents.AI.Workflows.

1. Граф: DialogExecutor (LLM-ход) → условный переход → ToolExecutor (read)
   → DialogExecutor | GateExecutor (write/destructive) | EscalateExecutor → End.
2. AgentFactory: собирает агента из agents тенанта (промпт, модель,
   активные тулы подключённых коннекторов). Кеш конфига — Redis, TTL 60 с,
   инвалидация при изменении конфигурации.
3. Чекпоинты: после каждого суперстепа state → checkpoints через
   StateContract (НЕ нативные структуры MAF). ResumeAsync восстанавливает
   и продолжает граф.
4. Version pinning: сессия продолжается на версии агента, с которой началась.
5. Для проверки графа сделай тестовый коннектор EchoTools (MCP-сервер,
   тулы echo_read (read) и echo_write (write)) по манифесту.
6. Тест: сессия с рестартом процесса между ходами — диалог продолжается.
