## Что сделано

### 1. Подключение и мастер в кабинете
- Провайдер `confluence` поддерживает:
  - **облачный Atlassian** — OAuth 2.0 (3LO), `accessToken` + `cloudId` (или автоопределение через `accessible-resources`), REST API **v2**;
  - **on-premise Server/DC** — API-токен/логин (`username` + `apiToken`) или Personal Access Token, REST API **v1**.
- Учётные данные вводятся в мастере, шифруются Secret Service (AES-256) и сохраняются только как `credentials_ref`.
- `TestConnection` проверяет реальные эндпоинты (`/wiki/api/v2/spaces`, `/rest/api/space`).
- После успешной проверки мастер загружает пространства и показывает их **чекбоксами**; выбор сохраняется в `config.spaces`.
- На шаге подключения выводится обязательное предупреждение:
  > В чат будут отвечать по всему содержимому выбранных пространств, доступному этому токену. Постраничные права доступа Confluence не проверяются в диалоге
- Исправлена ранее сломанная разметка страницы `Knowledge.razor` (таблица источников была вложена в форму).

### 2. Синхронизация
- **Полная выгрузка** выбранных пространств: страницы `storage`/HTML → чистый текст; медиа/вложения не индексируются (`TODO` фазы 4).
- **Инкремент по курсору**:
  - cloud — `GET /spaces/{id}/pages?sort=-modified-date`, плюс `status=trashed` для tombstone;
  - on-premise — CQL `lastmodified >= ...` через `/rest/api/content/search`;
  - перекрытие окна инкремента настраивается (`overlapMinutes`), уже применённые страницы повторно не индексируются.
- **Вебхуки** `page_created` / `page_updated` / `page_trashed`: created/updated запускают инкремент, trashed удаляет чанки по `external_id`. Поддержан Connect-вариант, где имя события передаётся не в теле, а в `?event=...`.
- **Иерархия страниц** сохраняется в metadata:
  - `folder` — «Раздел X → Подраздел Y»,
  - `extra.hierarchy` — полный путь «Пространство → Раздел → Страница»,
  - `space`, `url`, `author`, `modifiedAt`.
- **Устойчивость**: последовательная очередь запросов, таймауты, повторы при `429/5xx` с `Retry-After` и экспоненциальным backoff+jitter; заголовки `X-RateLimit-*` логируются. Ошибки прогона пишутся в `index_meta`, источник не удаляется.
