# Описание решения Agent Platform

Набор обзорных документов по реализованному решению. Это описание для общего понимания,
а не документация и не спецификация: детали контрактов и API смотрите в коде.

| Документ | Содержание |

| [solution-overview.md](solution-overview.md) | назначение платформы, архитектура, реализованный функционал и границы текущей версии |
| [projects.md](projects.md) | назначение, функционал и связи каждого проекта решения |
| [installation-and-administration.md](installation-and-administration.md) | установка (docker compose и локально), настройки, администрирование и диагностика |

Кратко о решении: мультиарендная платформа для AI-агентов на .NET 10, где агент — это
конфигурация (промпт, модель, набор тулов с политиками), диалог исполняется графом
Microsoft Agent Framework, действия write/destructive проходят через подтверждение
человеком, а состояние сессий хранится в нейтральном JSON-контракте в PostgreSQL.
В текущей версии работает сквозной сценарий «кабинет тенанта → агент → коннектор EchoTools →
HITL-гейт → подтверждение → исполнение»; внешние провайдеры модели, поиск по знаниям,
Telegram и панель оператора платформы ещё не реализованы.
